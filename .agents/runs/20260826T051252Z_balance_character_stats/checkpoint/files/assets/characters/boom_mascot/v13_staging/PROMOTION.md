# Gấu Nâu V13 golden-reference promotion

`boom_mascot` is the approved visual and animation reference for the V13 cast.
Its accepted V12 112×112, feet-anchored runtime frames are promoted unchanged
into the V13 staging contract: 15 actions and 84 frames. This intentionally
prevents the reference character from drifting while the other eight characters
are rebuilt to match it. Shared bubble/water VFX remain separate at runtime.
