# Manual Playtest Checklist

- [ ] F5 login/menu layout is readable at 960×720 and supported 4:3 resolutions.
- [ ] Solo options start the selected map/bot count/difficulty.
- [ ] Movement feels responsive; walls, soft blocks, and exited Water Balloons block correctly.
- [ ] Water Balloon appearance, wobble, POP, cardinal segments, end caps, and overlap cross read as water.
- [ ] Items are visible and all three upgrades update HUD/stats.
- [ ] Bot movement, placement, and escape look natural during a full match.
- [ ] Bubble contains the character, wobbles, times out, and produces the expected winner.
- [ ] Pause Resume/Restart/Main Menu work; Result Play Again/Main Menu work.
- [ ] Settings persist after restarting the executable.
- [ ] Local two-player controls work simultaneously on the target keyboard.
