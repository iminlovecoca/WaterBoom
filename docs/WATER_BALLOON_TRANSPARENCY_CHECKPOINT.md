# Water-balloon transparency checkpoint — 2026-08-25

## Runtime scope

The runtime catalog is intentionally limited to `skin_066` through `skin_081` (16 skins):

- `skin_066`–`skin_069`: Aqua Classic Reforge, Moonlit Abyss, Starlight Aurora, Watermelon Fresh.
- `skin_070`–`skin_079`: the ten previously supplied user balloon designs.
- `skin_080`: Bubble Star.
- `skin_081`: Cloud Pearl.

Older `skin_001`–`skin_065` folders are retained as recoverable source/rollback data only. They are no longer discoverable through the catalog, shop, inventory, network defaults, or gameplay fallback.

## Matte/background policy

Generated sheets may use solid magenta only as an intermediate chroma-key surface. The packaged runtime files under `assets/water_balloons/skins/` are RGBA PNGs with transparent corners and no shipped magenta background.

The cleanup pass is deliberately conservative: `tools/CleanWaterBalloonMatte.py` removes only low-alpha pixels that still match the magenta matte. It does not remove opaque lavender, purple, blue, pink, or other interior glass colors. This preserves the balloon's material while removing the colored halo that can appear on a contrasting map.

## Interior glass despill

The four translucent skins most likely to show a pink cast (`skin_078` Prism Pearl,
`skin_079` Jellyfish Bubble, `skin_080` Bubble Star and `skin_081` Cloud Pearl) also
receive a separate hue-only pass from `tools/DespillWaterBalloonMatte.py`. It is
restricted to the smooth upper membrane and only nudges magenta-dominant hues toward
the cool water hue. It preserves alpha, silhouette, highlights, bubbles, pearls,
stars and all other motifs; intentional pink/red/purple/green/gold skins are not
processed. The per-file pixel-change report is
`tests/artifacts/water_balloon_despill_report.json`.

## Validation

`tools/ValidateWaterBalloonAlpha.py` checks all 16 skins, five PNGs per skin (1 icon + 4 idle frames), transparent corners, non-empty alpha bounds, and visible matte-like pixels. The latest report is `tests/artifacts/water_balloon_alpha_validation.json` and passes for all 16 skins.

The visual QA sample `tmp/cloud_pearl_blue_bg.png` demonstrates Cloud Pearl composited over the in-game blue background: the glass tint remains visible, while the staging background is absent.

The full 16-skin QA board is `tests/artifacts/water_balloon_alpha_qa.png` and was
rebuilt after the despill pass. The current alpha validator remains green for all
16 skins, including icon and four idle frames per skin.

For a direct visual comparison, `tests/artifacts/water_balloon_despill_before_after.png`
shows the four affected skins on the same blue background before and after the
hue-only correction. It is generated by `tools/BuildWaterBalloonDespillQA.py`.
